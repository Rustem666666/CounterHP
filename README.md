# Счётчик здоровья для DND

## Описание проекта
Модифицированная версия прошивки к проекту "Читалка текста на Arduino"
- Три режима "Здоровье героя", "Альтернативная форма", "Временное здоровье"
- Разные скорости изменения счётчика при удержании кнопки
- Есть режим ожидания пока устройство не используется
Счётчик основан на проекте SDReader от AlexGyver https://github.com/AlexGyver/SDreader/
